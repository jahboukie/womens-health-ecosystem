# Sober Pal - AI-Powered Recovery Companion

A comprehensive mobile application designed to support individuals in their recovery journey from substance abuse, featuring AI-powered conversations, crisis intervention, progress tracking, and secure data management.

## 🎯 Project Overview

Sober Pal is a HIPAA-compliant mobile application that provides 24/7 AI-powered support for individuals in recovery. The app combines advanced AI technology with evidence-based recovery practices to offer personalized guidance, crisis intervention, and progress tracking.

### Key Features

- **AI-Powered Support Chat**: 24/7 conversational AI companion trained on recovery best practices
- **Crisis Detection & Intervention**: Real-time crisis detection with immediate resource provision
- **Progress Tracking**: Milestone tracking, mood monitoring, and coping strategy effectiveness
- **Secure Journal**: Encrypted personal journaling with AI-powered insights
- **Emergency Resources**: Instant access to crisis hotlines and professional support
- **HIPAA Compliance**: End-to-end encryption and secure data handling

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm
- PostgreSQL database
- Redis (for session management)
- Expo CLI for mobile development
- Docker (optional, for containerized deployment)

### Backend Setup

1. **Clone and install dependencies:**
```bash
cd backend
npm install
```

2. **Environment configuration:**
```bash
cp .env.example .env
# Edit .env with your configuration
```

3. **Database setup:**
```bash
npx prisma migrate dev
npx prisma generate
```

4. **Start development server:**
```bash
npm run dev
```

### Mobile App Setup

1. **Install dependencies:**
```bash
cd mobile
npm install
```

2. **Start Expo development server:**
```bash
npm start
```

3. **Run on device/simulator:**
```bash
npm run ios     # iOS simulator
npm run android # Android emulator
```

## 🔧 API Endpoints

### Authentication
- `POST /api/v1/auth/register` - User registration
- `POST /api/v1/auth/login` - User authentication
- `POST /api/v1/auth/logout` - Session termination

### AI Conversations
- `POST /api/v1/ai/conversation` - Start new conversation
- `POST /api/v1/ai/conversation/:id/message` - Send message
- `GET /api/v1/ai/conversations` - Get conversation history

### Crisis Support
- `GET /api/v1/crisis/resources` - Get crisis resources
- `POST /api/v1/crisis/:eventId/followup` - Submit crisis follow-up
- `GET /api/v1/crisis/events` - Get user's crisis events

### Progress Tracking
- `GET /api/v1/progress/dashboard` - Get progress dashboard
- `POST /api/v1/progress/milestone` - Add milestone
- `GET /api/v1/progress/coping-strategies` - Get coping strategies
