## 🚀 **QUICK START**

### **Prerequisites**
- Node.js ≥ 20.10.0
- npm ≥ 10.0.0
- Expo CLI
- Docker (optional)

### **Development Setup**
```bash
# Clone the repository
git clone https://github.com/jahboukie/womens-health-ecosystem.git
cd womens-health-ecosystem

# Install all dependencies
npm install

# Set up development environment
npm run setup:dev

# Start MenoTracker (mobile + backend)
npm run start:meno-tracker
```

### **Individual Platform Development**
```bash
# MenoTracker Mobile
npm run dev:meno-tracker

# MenoTracker Backend
npm run dev:meno-tracker:backend

# MenoPartner Mobile (when ready)
npm run dev:meno-partner

# MenoCommunity Mobile (when ready)
npm run dev:meno-community
```
